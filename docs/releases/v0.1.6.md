# v0.1.6 — potvrzení OCR oprav pro konkrétní verzi PDF

- Malé tlačítko **✓** vedle OK umožňuje potvrdit opravy aktuálně otevřeného PDF.
  Oranžová znamená čekající potvrzení, zelená potvrzené opravy. Opětovným kliknutím
  na zelené tlačítko lze potvrzení odvolat.
- Potvrzení vyžaduje dokončenou prohlídku (OK) a odstranění vyhovujících ponechaných
  připomínek pomocí ×. Nemění poznámky, připomínky ani stav prohlídky.
- Manifest automaticky zaznamenává SHA-256 PDF, čas potvrzení a historii rozhodnutí.
  Změna obsahu PDF vyžaduje nové potvrzení; stará historie zůstává zachována.
  Zastaralý dokument nebo souběžná změna manifestu nemůže přepsat novější práci.
- CSV export obsahuje stav potvrzení, čas a hash potvrzené verze PDF.
- Testy změny otevřeného PDF používají zápis kompatibilní s Windows.

Schéma manifestu zůstává 2 a starší manifesty bez potvrzení jsou podporovány.
Podrobnosti: [docs/region-review.md](https://github.com/triuk/pdf-ocr-reviewer/blob/v0.1.6/docs/region-review.md#version-bound-acceptance-of-repairs).
