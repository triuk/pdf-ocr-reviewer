# v0.1.7 — automatické načtení složky a práce s poznámkami

- Aplikace při spuštění automaticky načte PDF ze složky, ve které leží binárka,
  i při spuštění z jiného pracovního adresáře. Parametr `--folder` má přednost.
  Při spuštění ze zdrojových souborů se načte složka obsahující `main.py`.
- Instrukce manifestu ve verzi 5 popisují práci s uživatelskými poznámkami:
  poznámku k označenému místu, společnou poznámku k PDF a citovaný text dokumentu.
- Prázdná poznámka neruší označení. Nejasné, rozporné nebo částečně splněné
  požadavky zůstávají otevřené s konkrétním vysvětlením.
- Výsledky odpovídají na uživatelský požadavek bez přepisování původní poznámky.
  Souběžně změněné poznámky se znovu vyhodnotí a smazaná označení se neobnovují.
- Starší instrukce se migrují při zachování poznámek, označení, historie
  a vlastních rozšíření. Schéma manifestu zůstává ve verzi 2.

Ověřeno 96 Python testy, 26 JavaScript testy a self-testem aplikace.
